# QLM Staffing Platform — SPQ Demo A Bullhorn-style staffing CRM/ATS built specifically for Quality Labor Management's construction, solar, industrial, marine, civil, and mission critical staffing operations. ## Features - **Dashboard** — KPI cards, SPQ pipeline funnel, industry/branch charts, activity feed - **Team Members (ATS)** — Full candidate database with filtering by industry, branch, safety scores - **Job Orders** — Client job management with positions tracking, pay/bill rates - **Clients (CRM)** — Staffing client relationship management - **Customers** — End customer accounts (project owners where TMs work) - **Resume Database** — Search/filter all team member resumes and profiles - **AI Search & Match** — Intelligent matching of team members to jobs (and vice versa) - **SPQ Pipeline** — Kanban board matching QLM's hiring process - **Onboarding** — 8-step visual onboarding pipeline - **Automation** — 12 pre-built workflow automations - **Reports & Analytics** — Safety scores, hours, revenue, placements ## Quick Deploy (5 minutes) ### Option A: Deploy to Vercel (Recommended — easiest) 1. **Create a GitHub account** (if you don't have one): https://github.com/signup 2. **Create a new repository**: - Go to https://github.com/new - Name it `qlm-staffing-platform` - Click "Create repository" 3. **Upload these files** to the repository: - Click "uploading an existing file" - Drag the entire contents of this folder into the upload area - Click "Commit changes" 4. **Deploy on Vercel**: - Go to https://vercel.com and sign up with your GitHub account - Click "Add New Project" - Select your `qlm-staffing-platform` repository - Framework Preset: select **Vite** - Click "Deploy" - In ~60 seconds you'll get a live URL like `qlm-staffing-platform.vercel.app` ### Option B: Deploy to Netlify 1. Follow steps 1-3 above for GitHub 2. Go to https://app.netlify.com and sign up with GitHub 3. Click "Add new site" → "Import an existing project" 4. Select your repository 5. Build command: `npm run build` 6. Publish directory: `dist` 7. Click "Deploy site" ### Option C: Run Locally ```bash # Make sure you have Node.js installed (https://nodejs.org) cd qlm-staffing-platform npm install npm run dev ``` Then open http://localhost:5173 in your browser. ## Project Structure ``` qlm-staffing-platform/ ├── index.html # HTML entry point ├── package.json # Dependencies & scripts ├── vite.config.js # Build configuration ├── README.md # This file └── src/ ├── main.jsx # React entry point └── App.jsx # The entire application ``` ## Share with Your Team Once deployed, just send the URL to your team. No accounts or logins needed — it runs entirely in the browser. Everyone will see the same demo with freshly generated sample data. ## Notes - This is a **front-end prototype** using generated sample data - Data refreshes each time the page loads (not persisted) - All 150 team members, 50 jobs, 15 clients, and 20 customers are randomly generated - The AI matching engine runs real scoring logic against the sample data - To convert this into production software with real data, a backend database would need to be added --- Built for Quality Labor Management — *Safety, Productivity, and Quality Beyond the Job Site*
